# 실플레이 검증 절차서 (실제 사람 2~5명)

원칙
- 운영 규칙 그대로 검증한다. 최소 베팅·퇴장 규칙 완화 금지, 전용 완화 방 사용 금지.
- 테스트 중 자동 포인트 보충 금지. 시작 전에만 충분히 지급한다.
- 참가자는 서로 독립된 환경(다른 PC / 다른 브라우저 프로필 / PC+모바일)에서 각자 로그인한다.
  한 브라우저 세션에서 여러 계정을 동시에 띄우지 않는다.
- 새 버그가 실제로 재현되지 않으면 코드는 수정하지 않는다.
- 자동 스크립트 결과는 실플레이 PASS로 기록하지 않는다.

준비 상태 (2026-09-17 기준, 완료)
- test01~test05 게임 포인트 각 5,000,000P 지급 완료 (50판 이상 가능).
- 삭제된 방에 남아 있던 좌석 기록 0건으로 정리 완료.
- 활성 QA 방 없음. 검증 시 참가자가 로비에서 직접 방을 만든다.

## 5. 통과 기준

- 첫 클릭 실패 0 / 2~3번 눌러야 하는 현상 0 / 중복 처리 0
- 올인 후 불필요한 추가 베팅 0 / 필요한 올인 응답 누락 0
- 다이 후 멈춤 0 / 재경기 멈춤 0
- 준비 0/0 장시간 유지 0 / "좌석을 배정하는 중" 무한 대기 0
- 화면과 서버 상태 불일치 0 / 채팅 중단 0
- 체감 1초 이상 지연 0 (있으면 발생 시각과 화면을 기록)

## 6. 이상 발생 시

1. 발생 시각(초 단위), 방 번호, 판 번호, 계정, 누른 버튼, 화면 캡처를 남긴다.
2. 담당자에게 위 정보를 전달한다. 서버 기록과 대조해 원인을 확정한 뒤에만 최소 범위로 수정한다.
3. 재현되지 않으면 수정하지 않고 "재현 실패"로 기록한다.
