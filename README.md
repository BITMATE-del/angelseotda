> **상태: 초기 GitHub 등록 준비 중 — 서비스 소스는 아직 이 저장소에 업로드되지 않았습니다.**

기존 운영 버전의 게임 코어·정산·회원 데이터 보호를 최우선으로 합니다.

## 목표
- Telegram Mini App 전용 회원 접속(서버 측 인증 필수)
- 충전 수수료 0% / 출금 수수료 0%
- 정상 정산 판의 POT 운영 수수료 3%
- 땡값은 플레이어 간 이전, 운영사 땡값 수수료 없음
- 총판 리베이트는 게임 수수료 실수익을 기준으로 계산

## 필수 배포 검증
- 기존 Vitest 기준 346건 PASS 및 타입 검사·프로덕션 빌드 PASS
- 섯다 2장·3장, 도리짓고땡 실제 정산 QA
- 땡값 사전 예치·환급·사이드팟·재경기·중복 정산 테스트
- Telegram initData 서명·만료·직접 API 접근 제한 확인
- Supabase 마이그레이션은 별도 테스트 DB에서 검증 후 적용

**중요:** 운영 DB에 미검증 SQL을 직접 실행하거나 정산 기능을 먼저 활성화하지 않습니다.
