ANGEL SUTDA 2 CARD UI ASSET PACK
===================================

기준:
- 사용자 승인: 두 번째 에셋팩 스타일
- 실제 섯다 카드 앞면/뒷면은 기존 게임 에셋을 그대로 사용
- 이 ZIP 안의 UI 자산은 테이블/좌석/POT/버튼/상태/채팅/결과창/장식용
- 카드 지급 로직, 쪼기, 공개 타이밍, 카드 보안 로직은 변경하지 않음

권장 적용 경로:
public/assets/sutda/master_v1/

중요:
- 이 파일들은 승인된 마스터 에셋 시트에서 개별 요소별로 분리 저장한 전달용 패키지입니다.
- 라이브 닉네임/칭호/티어/포인트/상태/POT 금액은 HTML/CSS 오버레이로 렌더링하세요.
- 좌석 프레임 이미지 안의 예시 텍스트/프로필은 최종 라이브 데이터가 아니라 레이아웃 참고용입니다.
